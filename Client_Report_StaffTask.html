01 — Overview

What is StaffTask?

StaffTask is a web-based task management application designed specifically for small businesses that have both office managers and field staff. It gives managers full control over task assignment and monitoring, while providing field workers a simple, guided interface to complete and document their work.

💡 In simple terms: The manager creates jobs and assigns them to staff. Staff go to the location, do the work, upload a photo or video as proof, and mark it done — all from their phone or computer. No paper, no back-and-forth phone calls.

02 — User Roles

Two Roles, One System

The application has two clearly separated roles — each with the right tools for their job.

👨‍💼

Admin (Manager)

  • Create and assign tasks
  • Set priority levels and due dates
  • Drag tasks between status columns
  • Search and filter all tasks
  • View uploaded proof from staff
  • Track task progress in real time
  • Capture GPS location for tasks
👨‍🔧

Staff (Field Worker)

  • View only tasks assigned to them
  • Start a task with GPS check-in
  • Upload image or video as proof
  • Mark task as complete
  • View full task timeline history
  • Mobile-friendly interface
03 — Workflow

How It Works

The task moves through a simple, clear lifecycle from creation to completion:

1
Create Task
Admin creates and assigns task
2
Assign Staff
Task appears in staff's list
3
Start Task
Staff checks in with GPS
4
Upload Proof
Photo or video uploaded
5
Complete
Admin can see full record

Every step is automatically logged with a timestamp in the task's activity timeline.

04 — Features

Key Features

📋

Kanban Board

Visual board showing all tasks by status: To Do, In Progress, Review, and Complete. Drag and drop to update.

📍

GPS Location Tracking

Captures the staff member's exact GPS location when they start a task. Address is shown on a map.

📷

Proof of Work Upload

Staff can upload photos and videos directly from their device as evidence of completed work.

🔍

Search & Filter

Filter tasks by keyword, priority level, status, or assigned staff member instantly.

🕐

Activity Timeline

Every action on a task is automatically recorded with date and time — full audit trail.

💾

Auto-Save

All data saves automatically in the browser. Refreshing the page does not lose any data.

📱

Mobile Friendly

Fully responsive design — works on phones, tablets, and desktop computers without any app installation.

⚡

No Installation Needed

Opens directly in any web browser. No software to install, no account needed to get started.

07 — Future Growth

What Can Be Added Later

The current version is a fully working front-end application. When the business is ready to scale, the following enhancements can be added:

  • 1
    User Login System — Secure accounts with usernames and passwords so staff can only see their own tasks.
  • 2
    Backend Database — Store all data on a server so multiple users can share and sync data in real time.
  • 3
    Cloud File Storage — Upload proof photos and videos to cloud storage (e.g. AWS, Google Drive) to handle large files.
  • 4
    Push Notifications — Notify staff on their phone when a new task is assigned to them.
  • 5
    Reports & Analytics — Export task completion data, staff performance summaries, and monthly reports.
